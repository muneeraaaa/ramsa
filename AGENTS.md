# Codex ownership

Read README.md, CONTRIBUTING.md, TASKS.md and the shared design notes. Work on `codex/government-portal` or a focused `codex/` branch. Own government case files, review workflows, routing, shared architecture and GitHub Pages. Coordinate before editing `site/experience/` after the initial scaffold.

Use the shared bilingual records and UI helpers. Run `npm run check` plus a browser walkthrough in Arabic and English before opening a pull request. Keep sample assessments transparent and subject to human review.
