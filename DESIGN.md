# RAMSA design system

The visual references are the team’s Future Visions concepts. The site uses maritime green, warm sand, paper and dark ink from the art direction. English display type uses Georgia with Segoe UI for controls and body. Arabic uses Segoe UI with Tahoma as fallback. All routes inherit the same palette, typography, focus treatment, layout widths and controls from `site/shared/tokens.css` and `site/shared/style.css`.

The home screen is image-led. Government views favour compact, readable evidence. Immersive scenes give priority to their imagery and guide text. Keep text and controls readable over media and use the same control labels in the navigation and journey exits. Test both reading directions and support reduced motion.
